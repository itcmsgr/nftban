# NFTBan Branding Assets

This directory contains branding assets for NFTBan.

## Files:

- `logo.svg` - NFTBan logo (vector format, scalable)
- `logo.png` - NFTBan logo (raster format, 512x512)
- `favicon.ico` - Web reports favicon (16x16, 32x32, 48x48)

## Usage:

**HTML Reports:**
```html
<img src="/usr/share/nftban/branding/logo.png" alt="NFTBan" width="200">
```

**Documentation:**
Include logo in README, guides, and presentations.

**Web Interface:**
Use favicon in HTML reports and dashboards.

## License:

All branding assets are part of NFTBan and licensed under MPL-2.0.

## Customization:

To use custom branding:
1. Replace files in this directory
2. Maintain same filenames and formats
3. Rebuild reports/documentation
