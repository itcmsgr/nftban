Getting Started

1️⃣ Explore the Dashboard

Start by viewing real-time statistics, system health, and active protections.

2️⃣ Configure Protection

Enable/disable modules like Fail2Ban, Port Scan detection, and DDoS protection.

3️⃣ Manage IPs

Ban malicious IPs, whitelist trusted networks, and search for IP status.

4️⃣ Monitor Logs

View system logs, ban actions, port scan detections, and DDoS events.

Real-Time Dashboard

View live statistics from nftables: banned IPs, traffic, packets, and active connections. Auto-refreshes every 30 seconds.

Metrics:
  • Total banned IPs (permanent + temporary)
  • 24-hour ban activity
  • Bandwidth and packet statistics
  • Protection module status

IP Management

Search for IPs, view ban history, add to whitelist, or ban with custom timeout periods.

Actions:
  • Ban IP (permanent or with timeout)
  • Unban IP (remove from blocklist)
  • Whitelist IP or CIDR range
  • Search IP status and history

Protection Modules

Enable/disable Fail2Ban jails, port scan detection, DDoS protection, and geographical blocking.

Modules:
  • Fail2Ban integration (SSH, HTTP, etc.)
  • Port scan detection with configurable thresholds
  • DDoS rate limiting per IP
  • GeoBan country-based blocking

Safe Configuration

Edit .conf.local files with validation. Package defaults (.conf) are read-only for safety.

Features:
  • Syntax highlighting in editor
  • Automatic validation on save
  • Read-only package defaults
  • Override system for custom settings

Common Tasks

How to ban an IP address

  1. Click "IP Management" in the left menu
  2. Enter the IP address in the "Ban IP" field
  3. Optionally set a timeout (e.g., "24h", "7d", or leave empty for permanent)
  4. Click "Ban IP" button

How to whitelist an IP address

  1. Click "IP Management" in the left menu
  2. Scroll to "Whitelist Management"
  3. Enter the IP or CIDR (e.g., 192.168.1.0/24)
  4. Click "Add to Whitelist"

How to edit configuration

  1. Click "Configuration" in the left menu
  2. Select a .conf.local file from the dropdown
  3. Edit the file in the editor (syntax highlighting included)
  4. Click "Save" - validation runs automatically

How to view firewall logs

  1. Click "Logs Viewer" in the left menu
  2. Select a log type from the dropdown (ban.log, portscan.log, etc.)
  3. Choose number of lines to display (default: 100)
  4. Click "Load Log" to view

How to enable a protection module

  1. Click the module name in the left menu (e.g., "Port Scan Detection")
  2. Find the large toggle switch in the top-right corner
  3. Click the toggle to enable/disable
  4. Status will update immediately (ENABLED/DISABLED)

How to check IP status

  1. Click "IP Management" in the left menu
  2. Enter the IP address in the "Search IP" field
  3. Click "Search" button
  4. View ban status, source (Feed/Fail2Ban/Manual), and GeoIP info

CLI Integration

This GUI is a wrapper around the NFTBan CLI. All operations execute CLI commands with --json flag. The CLI is the source of truth.

Status Commands

# Check system status
$ nftban status --json
# View statistics
$ nftban stats --json
# Run health check
$ nftban health --json

IP Management Commands

# Ban an IP
$ nftban ban 192.0.2.10
# Ban with timeout
$ nftban ban 192.0.2.10 24h
# Search IP status
$ nftban search 192.0.2.10 --json

Module Commands

# Enable port scan detection
$ nftban portscan enable
# Check Fail2Ban status
$ nftban fail2ban status --json
# View DDoS stats
$ nftban ddos stats --json

Feed Commands

# List all feeds
$ nftban feeds list --json
# Update feeds
$ nftban feeds update
# Add custom feed
$ nftban feeds add custom https://...
