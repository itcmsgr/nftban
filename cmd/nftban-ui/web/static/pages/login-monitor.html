Login Monitor

NFTBan Login Monitor tracks SSH logins, SU/SUDO commands, and console access. Get real-time alerts with GeoIP enrichment.

Key Files:

  • /etc/nftban/conf.d/login_alert.conf - Default config
  • /etc/nftban/conf.d/login_alert.conf.local - User overrides
  • /var/log/nftban/login_alert.log - Event logs

Alerts: Email notifications sent via global mail system (NFTBAN_MAIL_RECIPIENT)
