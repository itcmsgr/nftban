# Contributing to nftban

Thanks for your interest in contributing!

## Code of Conduct
Be respectful and professional. By participating, you agree to foster a welcoming, harassment‑free community.

## Contribution License (Inbound = Outbound)
Unless you are notified otherwise in writing, **all contributions to the Core are licensed under the same license as the repository’s Core**:
**MPL‑2.0**. By submitting a pull request, you agree to license your contribution under **MPL‑2.0**.
- Do **not** copy Pro or confidential code into the Core repository.
- You must own the rights to your contribution or have permission to contribute it.

> If a separate **CLA** becomes necessary, maintainers will link it here. For now, no CLA is required.

## Developer Certificate of Origin (DCO)
To attest that you have the right to contribute, sign your commits with the DCO:
```
Signed-off-by: Your Name <you@example.com>
```
You can use `git commit -s` to sign automatically.

## How to Contribute
1. Fork the repo and create a feature branch.
2. Follow code style and include tests where relevant.
3. Include/maintain SPDX headers in modified files.
4. Ensure CI passes; update docs as needed.
5. Open a PR with a clear description and rationale.

## SPDX and Headers
Each source file must contain:
```
# Copyright (c) 2024–2026 NFTBAN Project / Antonios Voulvoulis
# SPDX-License-Identifier: MPL-2.0
```

## Security
If you discover a security issue, **do not** open a public issue. Email **security@nftban.com** with details and reproduction steps.
We will acknowledge receipt within a reasonable time and coordinate a fix and disclosure window.

## Governance
The project is maintained by the NFTBAN Project / Antonios Voulvoulis. We welcome community maintainers over time.
