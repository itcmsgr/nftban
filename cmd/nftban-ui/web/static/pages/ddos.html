About DDoS Protection

DDoS Protection leverages nftables rate limiting to monitor connection rates and automatically blocks IPs attempting distributed denial-of-service attacks.

Key Files:

  • /etc/nftban/conf.d/ddos.conf - Configuration
  • /var/log/nftban/ddos.log - Attack logs
  • /var/log/nftban/nftban-actions.log - Ban actions

Protection: Monitors connection rates per IP and blocks sources exceeding configured thresholds to prevent service disruption.
