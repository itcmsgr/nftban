```bash
NFTBAN_LOG_VARIABLE_DUMP="false"       # Variable dumps
```

### 🎯 RECOMMENDED: Enable Debug Logging for Stability Testing

**Option 1: Full Debug Mode (RECOMMENDED)**
```bash
# /etc/nftban/nftban.conf.local
NFTBAN_DEBUG_MODE="true"
NFTBAN_DEBUG_LOG_LEVEL="DEBUG"
NFTBAN_LOG_RETENTION_DAYS="7"   # Keep 7 days for analysis
```

**Option 2: Selective Module Debug**
```bash
# Debug specific modules only
NFTBAN_DEBUG_MODE="true"
NFTBAN_DEBUG_MODULES="feeds,fail2ban,geoip,ddos,portscan"
```

**Option 3: Trace Mode (VERY VERBOSE - Use Carefully!)**
```bash
# ⚠️  WARNING: Generates MASSIVE logs!
NFTBAN_DEBUG_MODE="true"
NFTBAN_TRACE_MODE="true"
NFTBAN_LOG_FUNCTION_TRACE="true"
```

### Log Files Created

When debug mode is enabled:

1. **Main Log** (always written):
   - `/var/log/nftban/nftban.log` - Human-readable

2. **Debug Log** (when DEBUG_MODE=true):
   - `/var/log/nftban/nftban_debug.log` - Detailed debug output

3. **Events Log** (structured):
   - `/var/log/nftban/events.jsonl` - Machine-readable JSON

4. **Actions Log** (from nftban-complete):
   - `/var/log/nftban/nftban-actions.log` - JSON log of all ban/unban

5. **Persistent Offenders Log**:
   - `/var/log/nftban/persistent-offenders.log` - Escalation events

6. **Cron Log**:
   - `/var/log/nftban/cron.log` - Scheduled task output

## 9. 📚 Quick Reference for User

### "Where Are My Reports?"

```bash
# Module report (shows all modules with versions and paths)
nftban module status
nftban module detailed

# Port report (shows services, ports, open/closed state)
sudo nftban port status
sudo nftban port detailed  # Shows process names too!

# FHS report (shows all directory paths and permissions)
nftban fhs status

# Statistics (bans, attacks, activity)
nftban stats

# Health check (system status)
nftban health check
```

### "Where Are Configuration Files?"

```bash
# Main config
/etc/nftban/nftban.conf

# Local overrides (your customizations)
/etc/nftban/nftban.conf.local

# Module configs
/etc/nftban/conf.d/

# Security profiles
/usr/share/nftban/profiles/

# Current profile
/var/lib/nftban/profile.current
```

### "Where Are Logs?"

```bash
# Main log (human-readable)
/var/log/nftban/nftban.log

# Debug log (when debug mode enabled)
/var/log/nftban/nftban_debug.log

# Events (machine-readable JSON)
/var/log/nftban/events.jsonl

# Ban actions (JSON)
/var/log/nftban/nftban-actions.log

# Persistent offenders
/var/log/nftban/persistent-offenders.log
```

### "What Version Am I Running?"

```bash
# Quick version
nftban --version

# Detailed version (backend)
/usr/sbin/nftban-complete --version

# All modules and versions
nftban module status
```

### "How Do I Enable Debug Logging?"

```bash
# Add to /etc/nftban/nftban.conf.local
NFTBAN_DEBUG_MODE="true"
NFTBAN_DEBUG_LOG_LEVEL="DEBUG"

# Reload (if running as service)
systemctl reload nftban

# Watch debug log
tail -f /var/log/nftban/nftban_debug.log
```
