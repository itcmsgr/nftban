# NFTBan Systemd Units - Canonical List

Canonical operator-facing inventory of NFTBan systemd units.
Filesystem source of truth: `install/systemd/*.{service,timer,socket}`;
package inventory projection: `install/packaging/systemd/nftban-systemd-install.list`.

> Counts in this document are CI-verified against
> `install/packaging/systemd/nftban-systemd-install.list`
> (generated by `build/generate-systemd-install-list.sh` from
> `install/systemd/*.{service,timer,socket}`).
> See `.github/workflows/ci-architecture.yml` "docs/systemd/UNITS.md count parity".

> **Schedule column note:** values reflect the unit file's `OnCalendar=` and
> `OnBootSec=` directives where applicable. The unit file is authoritative; this
> table is a curated projection.
