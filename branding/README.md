# Branding Guide (nftban)

This folder contains brand assets (logos, wordmarks). These assets are **not** covered by the MPL‑2.0 license.
Usage is governed by `TRADEMARK.md`.

**Rules:**
- Do not alter the logo (colors, proportions, effects).
- Do not combine with other marks or create confusingly similar branding.
- Keep clear space around the logo.
- Use only to indicate compatibility or community support unless you have **written permission**.
