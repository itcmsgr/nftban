## 🚨 If Your PC Crashes

### Quick Steps:
1. **Install Claude Code** on new PC
2. **Clone repository:** `git clone https://github.com/itcmsgr/nftban.git`
3. **Open in Claude Code** → Reads `CLAUDE.md` automatically
4. **Read these files** to catch up on what was done
