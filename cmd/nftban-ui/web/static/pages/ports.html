Manage firewall port whitelist - Allow or Block ports

How Port Control Works

NFTBan uses a whitelist-based firewall. By default, all ports are BLOCKED.

  • Allow Port = Add to whitelist (opens the port)
  • Block Port = Remove from whitelist (closes the port)
  • Ports not in the whitelist are automatically blocked by default DROP policy

CLI: nftban port add 8080 (allow) | nftban port block 8080 (block)
