Port Scan Detection

NFTBan Port Scan Detection monitors network traffic and automatically blocks IPs attempting to scan your ports.

Key Files:

  • /etc/nftban/conf.d/portscan.conf - Configuration
  • /var/log/nftban/portscan.log - Detection logs
  • /var/log/nftban/nftban-actions.log - Ban actions

Protection: Monitors TCP connection attempts to detect port scanning patterns and blocks malicious scanners automatically.
