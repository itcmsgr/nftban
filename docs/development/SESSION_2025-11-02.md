## 🐛 Bugs Discovered

### BUG-006: nftban.service uses non-existent command
**Severity**: Critical (blocks v0.10.0 release)
**Status**: Identified, not fixed

The service file references `nftban run` which doesn't exist.

**Current**:
```ini
ExecStart=/usr/sbin/nftban run
User=nftban
Group=nftban
```

**Error**:
```
ERROR: Unknown command 'run'
```

**Proposed Fix**:
```ini
ExecStart=/usr/sbin/nftban feeds update
User=nftban
Group=nftban
```

**Related**: BUG-007

---

### BUG-007: Missing Polkit rule for nftables commands
**Severity**: Critical (blocks v0.10.0 release)
**Status**: Identified, not fixed

The `nftban` system user cannot execute `nft` commands because there's no Polkit authorization.

**Error**:
```
ERROR: 'feeds update' requires root privileges
```

**Solution**: Add Polkit rule for `nftban` user (similar to fail2ban approach)

**Related**: BUG-006
